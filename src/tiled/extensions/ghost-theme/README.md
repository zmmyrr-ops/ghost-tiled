# 废弃主题工具

与 ghost-config 的 abandoned 主题素材及 theme_bake.py 配套使用。

将整个 ghost-theme 目录放入 Tiled 的 extensions 目录，重新加载扩展。菜单挂到自定义“猛鬼工具集”，无须修改 C++；现有构建配置自动打包 extensions/**。

提供方形地图主题应用、固定种子散布、沿墙草垛、三款静态设备放置、选择对象锁定。修改通过 map.macro 组织，原有 Bed/Collision 等工具代码不改动。

CLI 集成测试：

```sh
python3 tests/ghost-theme/run.py --tiled /path/to/Tiled --config-root /path/to/ghost-config --output /path/to/ghost-config/Map_model/Map_1001.tmx
```

测试内部设定资源根目录，正常编辑器按 TMX 上级目录寻找 Map_tsx。设备为纯视觉，放置后使用原生对象工具进行变换。人工拖动不会重新进行避让检查，发布前请检查门口与通道。

目前限制：100×100 格、正方形背景、顶层图层；框选按包围矩形处理；随机以贴墙加权抽样，尚未实现可调簇中心分布。后续可以增加背景九宫格、专用草垛角块和设备实际阻挡。


## 2026-10-12 修正

- 新增“重置装饰物”：默认清理未锁定自动装饰；也可清空全部草垛、散布和设备，保留底图、墙地及逻辑层。支持撤销，锁定图层需先解锁。
- 草垛改为单个上侧/侧面素材叠放，只在左、右、上侧生成；右侧水平镜像，不生成下侧草垛。
- 修复窗口关闭后读取已销毁控件导致的 undefined 数值错误，设备、散布和重置窗口均在关闭前保存输入。修正默认坐标/种子的控件范围初始化。
- 旧地图需重新点击“沿左 / 右 / 上侧外墙铺草垛”更新；旧锁定草垛需先解锁。


## 室内叶堆与统一面板

入口改为“猛鬼工具集 → 地图装饰面板…”，常驻非模态窗口集中管理主题、草垛、室内叶堆、纸片碎石、设备、锁定与重置。

叶堆不再进入随机池。ID 1 为室内贴墙叶堆，ID 2 重新裁切为室内角落叶堆。按 Floor 多边形及墙图块识别内边缘和角落，完整占地需位于房间内，并避开门、床等功能点。可选择贴墙、角落或两者；纯地面贴花不排除整片建造格。结果保存为 GhostTheme_RoomLeaves，已接入静态导出和重置。布置室内叶堆时清理旧 Scatter 中未锁定的自动叶堆，用户锁定内容保留。


叶堆定位修正：以墙根接缝为像素锚点，贴墙叶堆与角落叶堆覆盖墙脚 24 像素，允许图片横跨墙体与地面；不要求落在完整地板格中。房内朝向、门床避让和锁定规则保留。旧叶堆点击面板“贴墙根布置叶堆”重新生成。

新增 ID 12–18：两款草、两款单片小落叶、三款纸屑，均裁自参考设计 JPG 并清除连通地面底色。原 ID 0–11 不变。旧内嵌图集在使用工具时自动升级，保留已有实例。

统一面板新增“点缀墙根小草”；碎片素材可选混合、纸片/纸屑、碎石、零散小落叶。小草保持直立沿墙根点缀，室内叶堆继续由独立墙根规则生成。新增 GhostTheme_Grass 图层已支持重置、锁定和静态导出。


## 正式秋季资源

已导入 Desktop/秋季装饰元素 下的正式 PNG 资源，并用 Desktop/map03.png 直接替换主题墙地图集。正式图集使用 abandoned-map03-formal.tsx 与 abandoned-decorations-formal.tsx；保留原局部编号和装饰操作接口。试用样板 outputs/正式资源样板.png 已通过真实 Tiled 脚本加载与静态烘焙。


正式布局审查结论：设计稿采用“外围边界装饰 + 房间边缘装饰 + 少量中心碎片”的三级密度。墙外草垛只在上/左/右侧连续铺设，下侧留空；草垛遇门口或道路断开。墙根小草只补空档，最小间距 180 像素，避免与草垛连续重叠。室内叶堆只在 Floor 内墙根和角落，并压住墙脚 24 像素，避开 Door/Bed/Born/Supply。碎片按 1–3 个簇分布，边缘权重高于中心；设备附近提高碎片概率，房间中心保持空旷。正式规则配置见 decoration-rules-formal.json。
